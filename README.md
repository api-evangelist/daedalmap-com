DaedalMap resolves coordinates, place names, and reference codes into durable loc_id identities, reusable geometry, maintained data packs, and published crosswalks across geography families. It provides a hosted MCP and HTTP API for agents to access place identity services, geometry data, and curated data packs, enabling seamless integration into GIS workflows and data pipelines.

**Areas:** Geography · Data · Mapping · OpenSource · API
